# Заготовки экранов по архетипам

Читай, когда собираешь вайрфрейм-спецификацию или HTML-прототип. Это каркасы, а не дизайн: блоки, их порядок и поведение. Тексты в примерах – интерфейсные, поэтому в них длинное тире «—».

## Коллекция (таблица)

```
Заявки на отпуск                                     [+ Новая заявка]
[Мои на согласовании ▾] (не сохранено)  [Сохранить вид]
[Поиск по ФИО, номеру…]  [Статус: На согласовании ×] [Подразделение ▾] [Фильтры (2)]
Найдено 128                                  [Колонки] [Плотность] [⟳]
┌──┬─────────────────────┬──────────────┬──────────────┬────────┬──────────┐
│☐ │ Сотрудник           │ Подразделение│ Даты         │ Дней ↓ │ Статус   │
├──┼─────────────────────┼──────────────┼──────────────┼────────┼──────────┤
│☐ │ Соколова Мария      │ Аналитика    │ 12–25 авг    │     14 │ ● Ждёт вас│
│☐ │ Константинопольский…│ Казначейство │ 1–5 сен      │      5 │ ● Просрочена│
└──┴─────────────────────┴──────────────┴──────────────┴────────┴──────────┘
                                       ‹ 1 2 3 … 6 ›   50 на странице ▾

При выборе строк (прилипает снизу):
┌ Выбрано: 15 из 128  [Выбрать все 128]   [Согласовать] [Отклонить] [Выгрузить] [×] ┐
```

Поведение: фильтры и сортировка в адресе; клик по строке – боковая панель; `Enter` – открыть страницу записи; `J/K` – по строкам; `X` – выбрать строку.

## Таблица + панель (split view)

```
┌───────────────────────────────┬─────────────────────────────┐
│ Список (3–5 ключевых колонок) │ Соколова Мария     [↗] [×]  │
│ ▸ выбранная строка            │ Статус, ключевые поля       │
│                               │ [Согласовать] [Отклонить]   │
│                               │ История (последние 5)       │
└───────────────────────────────┴─────────────────────────────┘
```

Панель сбоку – если колонок мало; снизу – если колонок больше пяти или нужно сравнивать. `[↗]` – открыть полную страницу. При выборе нескольких строк – сводка по выбранным, а не пустая панель.

## Очередь (согласования)

```
Ждут вашего решения · 12           Сортировка: по сроку ▾
┌───────────────────────┬─────────────────────────────────────────┐
│ ● Соколова · отпуск   │ Отпуск 12–25 августа · 14 дней          │
│   срок завтра         │ Мария Соколова, ведущий аналитик        │
│ ○ Петров · командир.  │                                         │
│   через 3 дня         │ Остаток после отпуска: 0 дней           │
│ ○ Ли · отгул          │ В эти даты в отделе отсутствуют: 2 из 7 │
│                       │ Комментарий: «Свадьба сестры»           │
│                       │                                         │
│                       │ [Согласовать  A]  [Отклонить  R]        │
└───────────────────────┴─────────────────────────────────────────┘
После решения: «Согласовано — следующая: 2 из 12» и сразу следующая карточка.
```

## Карточка записи

См. схему в `SKILL.md`, раздел «Карточка записи». Обязательные части: шапка (что это, статус, ключевые поля, главное действие), «Следующий шаг» (если что-то ждут), вкладки по группам, история, связанные объекты с превью.

## Хаб

```
Отдел аналитики                           [Действия ▾]
Руководитель · 7 сотрудников · ФОТ (если есть права)
┌ Сотрудники (7) ──────────┐ ┌ Открытые вакансии (2) ────┐
│ 5 строк + «Все 7 ›»      │ │ 2 строки + [+ Вакансия]   │
└──────────────────────────┘ └───────────────────────────┘
┌ Отсутствия в этом месяце ┐ ┌ Заявки на согласовании ───┐
└──────────────────────────┘ └───────────────────────────┘
```

Не больше пяти элементов в превью, действия доступны прямо в блоке.

## Мастер

```
Приём на работу                             Черновик сохранён в 14:02
① Кандидат ✓ — ② Должность ● — ③ Условия — ④ Документы — ⑤ Проверка
[Назад]                                                   [Далее]
```

Шаги можно проходить назад без потери данных; последний шаг – сводка всех данных с правкой каждого блока; отправка – только с последнего шага.

## Дашборд

```
Требует внимания
┌ Просрочено согласований ┐ ┌ Заявки без ответственного ┐
│ 14  ↑ 5 к прошлой нед.  │ │ 3                          │
│ [Открыть список]        │ │ [Назначить]                │
└─────────────────────────┘ └────────────────────────────┘
Тренды
┌ Среднее время согласования, дни (норма ≤ 2) — график по неделям ┐
```

Каждое число – ссылка на отфильтрованный список.

## Командная палитра

```
┌ [ отп                                   ] ┐
│ Действия                                  │
│   Создать заявку на отпуск           N О  │
│ Записи                                    │
│   Соколова Мария — отпуск 12–25 авг       │
│ Разделы                                   │
│   Отпуска и отсутствия                    │
│ Недавнее                                  │
└───────────────────────────────────────────┘
```

Открывается `Ctrl/⌘+K`; синонимы и раскладка («jng» → «отп»); рядом с действием – его горячая клавиша.

## ИИ-панель на записи

```
┌ Помощник ─────────────────────────────── [×] ┐
│ [Сводка по сотруднику] [Черновик ответа]      │
│                                               │
│ Черновик — проверьте перед отправкой          │
│ …текст…                                       │
│ Основано на: заявка №1042, график отдела,     │
│ остаток отпуска на 05.11                      │
│ ⚠ Нет данных о командировках за август        │
│ [Вставить в ответ] [Изменить] [Ещё вариант]   │
└───────────────────────────────────────────────┘
```

Для действий с данными – экран «Будет изменено: было → стало» и подтверждение человеком.
